# Dedsafio Mobs Imitation — Minecraft 26.3 (Fabric)

Port a 26.3 del mod `dedsafio-mobs-imitation-mod-1.0.0` (1.21.1).

- Mobs: Nautilus Óseo Grande y Pequeño (vuelan, embisten y dan levitación), Cerebro Rojo y Cerebro Amarillo (se suben a la cabeza del jugador y le drenan vida; el rojo además controla al jugador para golpear a los de al lado).
- Arco Glebanoide (la flecha rebota de enemigo en enemigo), Arco de Huesos Grande (atraviesa 2), Espada Qumara.
- Plantillas de mejora, ámbar, materiales y huevos de spawn.

Necesita **Fabric API 0.166.2+26.3** y **GeckoLib 26.3-5.5.7** o más nuevos.
